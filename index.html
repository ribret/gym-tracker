Model: gradient boosting (full pooling across all 7 studios), retrained from scratch on every page build using all data collected so far, so the forecast improves automatically each day. Band = empirically calibrated 80% interval (measured coverage ≈ 79%). Dashed line (today only) = live adjustment: the gap between forecast and the measurements of the last hour is carried into the next hours and fades out (halved after about 80 minutes). In the backtest this cut the error for the next hour from 8.4 to 6.0 points; beyond 3 hours it adds nothing. Read the shape of the day rather than the exact peak height: mean error is about 7.5 points in the busy window (10:00 to 21:00) and near zero overnight. Weather: Open-Meteo.
